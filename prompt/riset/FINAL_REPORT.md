## Methodology

1. Collected journal data from https://sinta.kemdiktisaintek.go.id/journals
2. For each journal:
   - Visited SINTA profile page to get website URL
   - Visited journal website
   - Searched for template download links (PDF, DOC, DOCX)
   - Downloaded templates to respective rank folders

## Challenges

1. Many journals don't provide public templates
2. Some websites block automated requests (403 Forbidden)
3. Some require login to access templates
4. Templates hard to find (buried in menus)
