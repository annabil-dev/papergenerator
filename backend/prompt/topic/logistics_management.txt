   - 5-10 relevant formulas with variable definitions
   - Economic Order Quantity: EOQ = sqrt(2DS/H) where D=annual demand, S=ordering cost, H=holding cost per unit
   - Safety Stock: SS = z x sigma x sqrt(LT) where z=service level z-score, sigma=demand std dev, LT=lead time
   - Total Logistics Cost: TLC = Transportation Cost + Inventory Holding Cost + Warehousing Cost + Order Processing Cost
   - Fill Rate: FR = (Units Shipped / Units Ordered) x 100%
   - OTIF (On-Time In-Full): OTIF = (Orders Delivered On-Time AND In-Full / Total Orders) x 100%
   - Inventory Turnover: IT = COGS / Average Inventory Value
   - Vehicle Utilization: VU = (Actual Load / Vehicle Capacity) x 100%
   - Warehouse Space Utilization: WSU = (Used Storage Space / Total Available Space) x 100%
   - Total Cost of Ownership: TCO = Purchase Price + Operating Costs + Maintenance + Disposal - Residual Value
   - Carbon Emission per Shipment: CE = Distance x Weight x Emission Factor (kgCO2/ton-km)
